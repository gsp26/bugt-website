# Bugt website

Static landing page and privacy notice for Bugt. The site files are in this directory.

## Publish free with GitHub Pages

The app repository is private. GitHub Pages on GitHub Free requires a public repository, so publish only this `site/` folder from a separate public repository (for example, `bugt-website`) to keep the app source private.

1. Create a public GitHub repository for the website.
2. Copy the contents of this folder, including `.github/workflows/pages.yml`, to its repository root.
3. In **Settings → Pages**, choose **GitHub Actions** as the build and deployment source.
4. The included workflow builds and deploys the site whenever you push to `main`.
5. Push to `main`. GitHub will show the live URL in **Settings → Pages**.

The website can use the Bugt brand while the organization details are being prepared. Before using it for Google Play organization verification, make sure the website and account information identify the legal organization consistently with its D&B record.
